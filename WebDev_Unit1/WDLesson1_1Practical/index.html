Web Technologies

HTML

HTML is a markup language that is strictly for textual purposes in a website's code. It contrasts from CSS and JavaScript as those are decorative and interactory but HTML is essential for being the website itself. Although very simple, it is imperative to use so the coder is able to work to easily work with CSS and JavaScript.

CSS

CSS is a language used for decorative purposes in a website. As an example, if you use HTML for high quality text, CSS can be used to add a decoration such as a different hue and can let a website shift towards a professional side, playful side, etc. Through CSS, your website can transition from a dry and lifeless website to a decorative website properly fitting its genre.

JavaScript

JavaScript is a programming language that allows a user to utilize CSS and HTML for interactory purposes. As an example, through JavaScript, you are able to bring a darker hue to a button as you hover your mouse and changes the website as the user interacts with it. Overall, through JavaScript, you can allow the user to explore various sources and interact with your websites in an organized manner.
